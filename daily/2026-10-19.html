SAM3RL: Memory Control via Reinforcement Learning for Visual Object Tracking

SAM3RL：通过强化学习进行内存控制以实现视觉对象跟踪
2610.19931 · 2026-10-19 · Čížek, Tomáš
[EN] Segment Anything Model 3 (SAM 3) is a foundation model for image and video segmentation that sets the state of the art in visual object tracking. Its tracker, inherited from SAM 2, stores information from past frames in a memory bank, managed by a simple First-In-First-Out rule, allowing temporal consistency in complex videos. Several recent methods improve SAM 2 with hand-crafted memory update rules, each targeting a specific failure mode, such as distractors, occlusions, or object motion. However, their gains transfer only partially to the stronger SAM 3 backbone. We instead present a more general, data-driven approach that frames memory control as a sequential decision-making task. SAM3RL is an extension of the SAM 3 tracker with a lightweight memory controller, trained by reinforcement learning, that decides which frames enter the memory bank in order to maximize tracking performance. SAM3RL sets a new state of the art on 10 of 12 tracking and video object segmentation benchmarks, outperforming all hand-crafted rules without any runtime overhead. The same approach applied to SAM 2 gives SAM2RL, which outperforms hand-crafted rules on 9 of the 12 benchmarks, showing the generality of our method across model generations.
[中文] Segment Anything Model 3 (SAM 3) 是图像和视频分割的基础模型，它设定了视觉对象跟踪的最先进技术。它的跟踪器继承自 SAM 2，将过去帧的信息存储在内存库中，并通过简单的先进先出规则进行管理，从而实现复杂视频的时间一致性。最近的几种方法通过手工制定的内存更新规则改进了 SAM 2，每种规则都针对特定的故障模式，例如干扰物、遮挡或物体运动。然而，他们的收益仅部分转移到更强大的 SAM 3 主干网。相反，我们提出了一种更通用的数据驱动方法，将内存控制构建为顺序决策任务。SAM3RL 是 SAM 3 跟踪器的扩展，具有轻量级内存控制器，通过强化学习进行训练，决定哪些帧进入内存库，以最大限度地提高跟踪性能。 SAM3RL 在 12 个跟踪和视频对象分割基准中的 10 个上设置了新的技术水平，超越了所有手工制定的规则，且没有任何运行时开销。应用于 SAM 2 的相同方法给出了 SAM2RL，它在 12 个基准测试中的 9 个上优于手工制定的规则，显示了我们的方法在模型代之间的通用性。
